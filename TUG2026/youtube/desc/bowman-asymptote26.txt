Asymptote has undergone substantial evolution in recent years, spanning language enhancements, rendering backends, and web deployment. New language features—including templated imports, the using and autounravel keywords—have simplified coding. A collections library, contributed by Charles Staats, introduces hash maps, B-tree maps (which maintain sorted order), hash sets, sorted sets, and queues as templated modules, along with iterator utilities such as zip and enumerate. These are supported by language-level additions: user-defined structs can now be iterated with range-based for loops via an operator iter method, support bracket indexing through operator[] and operator[=], and benefit from native hashing of ints, strings, reals, and int arrays. Together, these features broaden the range of algorithms that can be expressed concisely in Asymptote.

The AsyGL library has made it straightforward to embed interactive 3D figures directly in HTML, allowing Asymptote scenes, including WebGL animations, to be displayed on tablets and phones.

The rendering pipeline has seen major changes: the legacy OpenGL renderer is being superseded by a Vulkan port to support order-independent transparency across all major platforms, including macOS. The upcoming migration from WebGL to WebGPU will bring that same order-independent transparency to web browsers.

Additional highlights include the Qt6 upgrade of the Xasy graphical front end, image-based lighting, B'ezier triangle patches, a portable compressed V3D file format that can be embedded in PDFs, and a V3D-aware plugin for Okular. We survey these developments, demonstrate live examples, and discuss what lies ahead for Asymptote as a vector graphics language designed to complement TeX for technical illustration.
