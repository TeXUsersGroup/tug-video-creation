Donald Knuth's WEB system of literate programming spawned many other WEB-like frameworks that worked, well, mostly like WEB. But one of WEB's ancestors did its tangling differently, in a way that gave code chunks a kind of scope. We look at this once-extinct feature from Pierre-Arnoul de Marneffe's language of “holons”, and note its sudden reappearance in a recent literate programming tool.
